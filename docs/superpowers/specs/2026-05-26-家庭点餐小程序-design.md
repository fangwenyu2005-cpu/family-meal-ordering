# 家庭点餐小程序 — 设计方案

**日期**: 2026-05-26
**状态**: 已确认，待实施

---

## 一、项目概述

咖啡馆/茶饮/烘焙店的点餐系统，包含顾客扫码点餐小程序、商家管理网页端、Node.js 后端服务、Neon PostgreSQL 数据库。

### 核心场景

1. 顾客扫桌上二维码 → 自动获取桌号 → 浏览菜单 → 选规格 → 加入购物车 → 提交订单（选择堂食/打包）→ 到店付款
2. 商家登录管理网页 → 查看仪表盘 → 接单/管理订单 → 管理菜单 → 查看流水统计

---

## 二、技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 点餐端 | 原生微信小程序 (WXML/WXSS/JS) | 顾客扫码进入 |
| 商家端 | React + Ant Design / TDesign | 独立网页（H5） |
| 后端 | Node.js + Express | REST API |
| ORM | Prisma | 类型安全，自动迁移 |
| 数据库 | Neon PostgreSQL | 通过 MCP 管理 |
| 部署 | 微信云托管（Docker） | 自动构建部署，免运维 |
| 图片存储 | 微信云存储 / 云托管静态资源 | 商品图片 |

---

## 三、系统架构

```
点餐端(小程序) ──→ Node.js API ──→ Neon PostgreSQL
                      │
商家端(React H5) ────┘

部署: git push → 微信云托管 Docker 构建 → 自动上线 → HTTPS 域名
```

- 点餐端和商家端共用同一套 API
- 商家端管理接口需要登录鉴权（JWT）
- 二维码通过微信 `wxacode.getUnlimited` 生成，携带桌号参数

| 字段 | 类型 | 说明 |
|------|------|------|

### 定价逻辑

- 商品有 `base_price`（默认中杯价）
- 规格选项有 `price_delta`，杯型（中杯 0，大杯 +4），温度/糖量 = 0
- 下单时单价 = base_price + Σ(所选 spec_option.price_delta)

## 五、API 接口

### 菜单（公开）
- `GET /api/categories` — 分类列表
- `GET /api/products?category=1` — 菜单列表（按分类筛选）
- `GET /api/products/:id` — 单品详情 + 可选规格

### 桌号（公开）
- `GET /api/tables/:code` — 验证桌号是否有效

### 订单（公开）
- `POST /api/orders` — 提交订单
  ```json
  { "table_id": 1, "dine_type": "EAT_IN", "items": [...] }
  ```
- `GET /api/orders/:id` — 查询订单状态
- `PATCH /api/orders/:id/cancel` — 取消订单（仅 SUBMITTED 状态）

### 商家管理（需 JWT 鉴权）
- `GET /api/admin/orders?status=xx` — 订单列表
- `PATCH /api/admin/orders/:id/status` — 更新状态
- `POST /api/admin/products` — 新增单品
- `PUT /api/admin/products/:id` — 编辑单品
- `DELETE /api/admin/products/:id` — 删除单品
- `POST /api/admin/tables` — 创建桌号 + 生成小程序码
- `GET /api/admin/qrcode/:tableId` — 下载桌号二维码
- `POST /api/admin/login` — 商家登录
- `GET /api/stats/overview` — 今日/本周/本月概览
- `GET /api/stats/ranking` — 单品/分类销量排行

### 订单状态流转

```
SUBMITTED → CONFIRMED → PREPARING → COMPLETED
     │
     └── CANCELLED（仅此状态可取消）
```

## 七、规格说明

### 预设数据

**3 个规格组：**
- 杯型（必选）：中杯 +0、大杯 +4
- 温度（必选）：热 +0、冷 +0
- 糖量（可选）：全糖 +0、半糖 +0、无糖 +0

**3 个分类、15 款单品：**
- ☕ 经典咖啡：美式(18)、拿铁(24)、卡布奇诺(24)、摩卡(26)、浓缩(16)、冷萃(22)
- 🍵 茶饮：抹茶拿铁(26)、伯爵红茶(20)、水果茶(22)、柠檬苏打(18)
- 🍰 甜品：提拉米苏(32)、巴斯克芝士(28)、抹茶千层(30)、可颂(16)、司康(14)

### 规格与商品关联
- 咖啡类（除冷萃/浓缩）→ 杯型 + 温度 + 糖量
- 冷萃/浓缩 → 杯型 + 糖量
- 伯爵红茶 → 杯型 + 温度
- 水果茶/柠檬苏打/抹茶拿铁 → 杯型 + 糖量
- 甜品 → 无规格
